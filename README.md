# 量子计算机 3D 原理探索

用 Three.js 精细建模一台超导量子计算机，并通过 7 个交互章节解释：**量子计算机是什么、靠什么工作、为什么在某些问题上能快得惊人**。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 http://localhost:5173）。`npm run build` 可生成静态站点到 `dist/`。

## 章节

| # | 章节 | 内容 |
|---|------|------|
| 1 | 硬件结构 | 稀释制冷机“金色吊灯”：6 级温区板（300 K → 10 mK）、G10/镀金支撑杆、脉冲管冷头、蒸馏室、螺旋连续热交换器、银烧结热交换器、混合室、24 根同轴线（含衰减器、HEMT 放大器、环行器）、样品盒、芯片、磁屏蔽与可切换的剖面真空罩/辐射屏蔽；微波脉冲沿线缆流动 |
| 2 | 量子芯片 | 5×5 Xmon transmon 芯片：十字形比特、可调耦合器、蛇形读出谐振腔、控制线、读出总线、空气桥、SQUID/约瑟夫森结、磁通钉扎孔、引线键合、PCB 与 SMP 接头；随机量子线路动画（单比特门 → CZ 门 → 读出） |
| 3 | 叠加态 | 交互式布洛赫球：X/Y/Z/H/S/T/Rx/Ry 门以旋转动画呈现，θ/φ 滑块直接设定量子态，单次测量坍缩与 100 次统计 |
| 4 | 纠缠 | 两个布洛赫球 + 4 个基态振幅柱：H + CNOT 制备贝尔态，单比特矢量缩到球心，测量一方另一方立即确定，1000 次重复实验统计 |
| 5 | 指数空间 | 1–10 个比特的 2ⁿ 振幅柱阵（高度 = 幅值，颜色 = 相位），H⊗n 两次演示相消干涉，Bernstein–Vazirani 一次查询读出隐藏串，经典模拟内存表 |
| 6 | 量子搜索 | Grover 算法：oracle 相位翻转 + 关于平均值反射的振幅放大动画，与经典逐个检查同步比赛；几何旋转图与成功概率曲线 |
| 7 | 为什么快 | 叠加 / 纠缠 / 干涉三大支柱；RSA 分解（数域筛 vs Shor）与无序搜索（N/2 vs √N）的 3D 对数柱状图；局限与应用 |

所有量子行为都由 `src/quantum.js` 中的态矢量模拟器真实计算，而非预设动画。

## 结构

```
src/
  main.js          渲染器、泛光后期、相机过渡、章节切换
  quantum.js       态矢量量子模拟器（门、测量、约化布洛赫矢量）
  chipLayout.js    芯片版图数据 + 程序化生成的芯片表面纹理
  blochSphere.js   可复用的布洛赫球组件
  util.js          DOM/标签/补间/材质工具
  scenes/          7 个章节
```

操作：左键拖动旋转 · 滚轮缩放 · 右键平移 · 数字键 1–7 切换章节。
